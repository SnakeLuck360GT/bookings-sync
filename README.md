# Bookings

See which study rooms your group has booked at the University of Manchester, and the gaps still to book.

I made it because my group kept sending each other screenshots of booking emails to work out who had booked what.

<p>
  <img src="docs/screenshot.png" width="48%" alt="A day's bookings and gaps">
  <img src="docs/proof.png" width="48%" alt="Proof of a booking">
</p>

## Using it

1. Create a group with your name and your My Manchester timetable link.
2. Send the group code to your friends so they can log in and add theirs.
3. Rooms you book through Resource Booker show up automatically.

Tap a gap to book it, or a booking to show proof.

## Running it

```bash
npm install
npm run dev
```

Deploy by importing the repo into Netlify. More detail is in [docs/how-it-works.md](docs/how-it-works.md).
